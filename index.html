About This Project

A cloud-powered Lost & Found management system for HSTU campus — connecting finders with owners using free cloud infrastructure.

☁️

Cloud Powered

All data lives in Firebase — always in sync, zero server cost.

🔐

User Accounts

Register and login to report items, make claims, and track your history.

✅

Admin Approval

Every post is reviewed by admin before going public — ensuring quality content.

📊

Admin Dashboard

Full control panel to manage users, moderate content, and process claims.

🔔

Private Claims

Finder contact details stay private until a claim is approved, then sent by email.

📱

Mobile Ready

Works perfectly on any device — phones, tablets, or desktop.

⚙️ Technology Stack

Firebase Authentication Cloud Firestore Cloudinary Google Apps Script (Mailer) GitHub Pages HTML5 / CSS3
